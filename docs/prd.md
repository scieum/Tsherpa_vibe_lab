# T셀파 중등 과학 바이브코딩 PRD

## 1. 목적
중등 과학 수업에서 교사와 학생이 보고 직접 조작하며 개념을 이해하도록 돕는
단원별 인터랙티브 수업 자료를 바이브코딩으로 만든다.
디자인은 모든 단원에서 같게 유지하고, 단원마다 하위 폴더에 새 페이지를 만든다.

## 2. 한 문장 정의
교사가 수업에서 바로 띄워 쓰고, 학생이 직접 조작하며 개념을 확인하는
디자인이 통일된 단원별 과학 시뮬레이션 페이지.

## 3. 사용자
- 교사: 수업에서 시연하고 사용 방법을 안내한다.
- 학생: 조건을 바꿔 보며 관찰하고 퀴즈로 이해를 점검한다.
- (하네스 쪽) 검수자: 당분간 제작자 1인이 겸한다.

## 4. 단원 페이지 공통 구성 (공식 템플릿 T_Fixed / T_Floating 기준)
1. 제목 + T셀파 로고 (로고 클릭 시 T셀파 이동) — 필수
2. 학습 가이드: 헤더 ? 버튼 → 팝업 (콘텐츠 소개, 사용 방법) — 필수
3. 전체화면 버튼 — 필수
4. 시뮬레이션 캔버스 + 초기화 버튼 — 필수 / 제어 패널: 오른쪽 고정(T_Fixed) 또는 떠 있는 패널(T_Floating)
5. 개념 정리 팝업 — 필요 없으면 삭제
6. 확인 퀴즈 팝업: 문항 이동, 정답 확인 — 필요 없으면 삭제
7. 음량, 확대/축소, 드래그, 변수/조건 안내 — 필요 없으면 삭제
8. 하단 저작권 표기 — 필수

## 5. 레퍼런스(허들링 PRD)에서 바꾼 것
- 판매, 마켓, 정산, 멤버십 권한 → 제외
- design.md → 공식 템플릿 2종과 제작 안내 PDF(`ref/`)를 기준으로 만든다 (2026-11-12)

## 6. 조건
- 과학 개념이 교과서·성취기준과 달라서는 안 된다.
- 타인의 저작물(이미지, 데이터, 문항)은 출처나 권리를 확인한 뒤에만 넣는다.
- 모든 단원은 같은 design.md를 따른다.
- 결과물은 AI 에이전트가 읽고 이어서 작업할 수 있는 구조여야 한다.

# 서비스 맥락 (story-service)

## 유저스토리
1. 교사가 단원 시뮬레이션을 수업 화면에 띄워 개념을 시연한다.
2. 교사가 학습 가이드를 보고 사용 방법을 학생에게 안내한다.
3. 학생이 조건(물질, 각도, 기간 등)을 바꿔 가며 결과를 관찰한다.
4. 학생이 개념 정리를 읽고 확인 퀴즈로 이해했는지 점검한다.

## 이 서비스에서 어기면 안 되는 것 (판정 기준)
- N1. 교과서·성취기준과 다른 과학 개념을 보여주지 않는다.
- N2. 타인의 저작물을 출처·권리 확인 없이 넣지 않는다.

※ N1·N2는 작업 흐름(R1-B)의 재료가 아니라 R5 게이트의 판정 기준으로만 쓴다.

# 목적 (purpose)

## 매번 달라지는 것 (단원 입력)
단원 입력 파일 1개에 아래 4개 칸이 모두 채워져 있어야 시작할 수 있다.
1. 단원명, 학년, 영역 (예: 중2 / 물리 / 빛의 반사와 굴절)
2. 성취기준 코드와 문장
3. 조작 변수 (예: 물질, 입사각 0°–85°)
4. 개념 정리 문구와 퀴즈 문항

그 외(디자인, 화면 구성, 섹션 순서)는 모든 단원에서 같다. 단원마다 고르는 것은 템플릿 유형(T_Fixed/T_Floating)과 지울 기능뿐이며, S1이 정한다.

## 하네스 사용자
- 제작자 1인 (검수자 겸임). 검수자가 따로 생기면 R6에서 역할을 나눈다.

## 완료 기준 (한 문장)
단원 폴더 1개에 `index.html`(+ 필요하면 `contents/`)이 있고, 필수 섹션(제목, 학습 가이드, 시뮬레이션, 저작권 + 지우지 않은 개념 정리·확인 퀴즈)이 모두 있으며, 판정 스크립트를 0건 실패로 통과하고, 검수자가 실제 기기·브라우저까지 확인해 승인했고, 전달용 zip이 만들어졌다.

- 필수 섹션 모두 (개념 정리·확인 퀴즈는 `removed_features`에 없으면 필수)
- 판정 실패 0건
- 승인 기록 1건
- `<폴더명>.zip` 1개

## 퀴즈 결과
- 저장하지 않는다. 정답 확인만 하고 새로고침하면 사라진다.
- 서버 전송, 브라우저 저장(localStorage 등) 모두 하지 않는다.

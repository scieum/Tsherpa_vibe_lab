## 4. 결정·주의 사항

| 항목 | 내용 |
|---|---|
| 그림은 코드로 (2026-10-18 결정) 유지 | PDF는 contents/ 이미지를 허용하지만, 기구·물체는 계속 코드로 그리는 것이 기본. contents/는 출처가 있는 파일(효과음 등)용. clarchive 참고 그림은 넣지 않음 |
| 변수/조건 안내 한 곳 | PDF "중복 표기할 필요 없음"을 **한 곳만 쓰기 규칙**으로 강제함 (G1). 둘 다 필요하다면 이 규칙을 완화해야 함 |
| 패널 삭제 시 안내 문구 | 템플릿 ZONE G는 시작 버튼이 없으면 안내를 갱신하지 않아 "로딩 중..."에 멈춤 → 패널 삭제 시 `#helperText` 묶음도 지우도록 규칙화 (캡처로 확인) |
| 퀴즈 정답 줄바꿈 | 공식 템플릿은 정답을 textContent로 넣어 `\n`이 보이지 않음 → 정답·해설을 한 문단으로 쓰도록 변경 (옛 임시 템플릿의 pre-line 수정은 공식 템플릿에 없음) |
| 기존 단원 4개 | `units/chem/*` 3개, `units/phy/m2_light_reflection_refraction`은 옛 임시 템플릿 기준이라 새 G3에서 `template` 없음으로 실패 (S1). 손대지 않음 — 이어서 할 때 S1·S3 재작업 여부를 물음 |
| 실행 환경 | 하네스는 macOS 기준. Windows에서는 `CHROME_PATH`·`python` 필요, `extract_textbook.js`(osascript)·`chrome.py`(Apple Events)는 Windows에서 동작 안 함 |

## 1. 단원
- 단원명: 밀도 차를 이용한 혼합물의 분리
- 학년: 중2
- 영역: chem
- 영어 폴더명: m2_density_separation

## 2. 성취기준
- [9과08-03] 물질의 특성을 이용하여 혼합물이 분리되는 원리를 이해하고, 이를 이용한 사례를 주변에서 찾을 수 있다.
- 성취기준 적용 시 고려사항: 혼합물의 분리 방법과 원리를 이해하는 수준에서 다루며, 혼합물의 분리 결과를 확인하는 활동을 할 수 있다.
- 출처: 2022 개정 교육과정 과학과 중학교 '(8) 물질의 특성' (나무위키 2차 자료, 공식 원문 대조는 G4에서)

## 3. 조작 변수
- 모드: 액체 혼합물 / 고체 혼합물 (선택)
- [액체 모드] 혼합물: 물 + 식용유 / 물 + 에탄올(섞이는 액체 — 층이 생기지 않는 대비 사례, 임성숙 지도서 오개념 근거)
- [액체 모드] 분별 깔때기 조작(교과서 순서): 마개 열기 → 꼭지 열어 아래층부터 받기 → 경계면 직전에 꼭지 닫기 → 위층은 입구로 따르기. 마개를 닫은 채 꼭지를 열면 잘 내려오지 않음 안내
- [고체 모드] 혼합물: 플라스틱(PET·LDPE·PS) 혼합물 / 볍씨(쭉정이 + 알찬 볍씨)
- [고체 모드] 분리용 액체: 플라스틱 → 물 / 글리세롤 (정대홍 교과서 '해 보기'), 볍씨 → 소금물
- 에탄올에 고체 넣기, 덜 여문 볍씨, 스타이로폼+모래는 넣지 않는다 (교과서 근거 없음, 2026-10-18 결정)
- 밀도는 수치 대신 "더 크다/작다" 비교로 표시한다 (수치는 시뮬레이션 내부 판정에만 사용, 교과서 쪽 출처 명시)
- 일러스트: clarchive.co.kr에서 사용자 승인 후 assets/에 받는다 (출처 기록)

## 4. 개념·퀴즈 메모
- 개념: 밀도가 큰 물질은 아래로 가라앉고 작은 물질은 위로 뜬다 / 고체 혼합물 분리용 액체는 밀도가 두 고체 사이이고 두 고체를 녹이지 않아야 한다 / 서로 섞이지 않는 액체는 분별 깔때기로 분리 / 생활 사례(교과서 표기): 소금물로 볍씨 고르기, 기름막이, 달걀 고르기, 키질 — 사금은 넣지 않음
- 밀도 계산(질량÷부피)은 개념·퀴즈에 쓰지 않는다.
- 퀴즈 3문항 이상

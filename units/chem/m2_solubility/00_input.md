## 1. 단원
- 단원명: 용해도
- 학년: 중2
- 영역: chem
- 영어 폴더명: m2_solubility

## 2. 성취기준
- [9과08-01] 물질의 특성의 의미를 알고, 실험을 통해 밀도, 용해도, 녹는점, 끓는점 등을 설명할 수 있다.
- 출처: 2022 개정 교육과정 과학과 중학교 '(8) 물질의 특성' (S0에서 지도서 원문으로 확인)

## 3. 조작 변수
- 용질: 질산 칼륨 / 질산 나트륨 / 황산 구리(Ⅱ) / 염화 나트륨 (두 출판사 공통 4종, 값은 임성숙 지도서 p.112 표, 2026-10-18 R 대조 결정)
- 용매: 물 100 g (고정)
- 넣는 용질의 질량: 슬라이더 (g, 범위는 S0 값으로 확정)
- 온도: 슬라이더 0~100 ℃ (교과서 곡선 범위). 곡선 세로축 0~180 g, 넘는 구간은 화살표로 표시
- 석출: 온도를 낮춰 녹아 있는 양이 용해도보다 많아지면 비커 바닥에 결정이 생기는 모습과 '석출' 용어만 정성적으로 보여준다 (정대홍 p.19). 석출량 계산·재결정은 넣지 않는다
- 비커에서 모두 녹음/녹지 않고 남음(포화·불포화)을 보여주고, 용해도 곡선 위에 현재 상태(온도, 녹인 양) 점을 표시한다.
- 기구는 코드로 직접 그린다 (앞 단원 스타일). 필요하면 SA에서 참고 그림만 고른다.

## 4. 개념·퀴즈 메모
- 개념: 용해도의 정의(일정한 온도에서 용매 100 g에 최대로 녹을 수 있는 용질의 g 수) / 포화 용액·불포화 용액 / 용해도는 물질의 특성(종류마다 다름) / 온도에 따라 달라짐 / 용해도 곡선 읽기
- 기체 용해도(온도가 낮을수록·압력이 높을수록 큼, 탄산음료 사례)는 시뮬레이션 없이 개념 카드 1장 + 퀴즈 1문항 (두 교과서 본문)
- 지도서 오개념 반영: 저으면 용해 속도만 빨라짐 / 빨리 녹는다고 용해도가 큰 것 아님 / 곡선 위 점 = 포화, 아래 = 불포화
- 재결정·석출량 계산은 넣지 않는다 ([9과08-03]).
- 퀴즈 5문항, 용해도 곡선 해석 포함. 보기 형식은 design.md 5장 규칙.

## 1. 단원
- 단원명: 끓는점과 녹는점
- 학년: 중2
- 영역: chem
- 영어 폴더명: m2_boiling_melting_point

## 2. 성취기준
- [9과08-01] 물질의 특성의 의미를 알고, 실험을 통해 밀도, 용해도, 녹는점, 끓는점 등을 설명할 수 있다.
- 출처: 2022 개정 교육과정 과학과 중학교 '(8) 물질의 특성' (S0에서 지도서 원문으로 확인)

## 3. 조작 변수
- 모드: 끓는점 / 녹는점·어는점 (선택)
- [끓는점] 물질: 물 / 에탄올 (에탄올은 물중탕으로 가열), 양: 적음 / 많음 — 두 교과서 공통 탐구
- [녹는점] 물질: 팔미트산 / 로르산 (정대홍·임성숙 그래프), 양: 적음 / 많음
- [녹는점] 다 녹은 뒤 '냉각' 버튼으로 같은 그래프에 이어 그려 가열냉각 곡선 완성 → 녹는점 = 어는점 표시 (정대홍 p.24 그림 근거, 냉각 방법은 그리지 않음)
- 압력은 조작 변수에서 빼고 화면에 '1기압에서' 조건만 표시 (2026-10-18 R 대조 결정)
- 가열 / 냉각 시작·일시정지
- 시간-온도 그래프가 실시간으로 그려지고, 상태가 변하는 동안 온도가 일정한 구간을 확인한다. 양을 바꿔도 끓는점·녹는점은 같고 도달 시간만 달라짐을 비교한다.
- 기구(가열 장치, 시험관·비커, 온도계)는 코드로 직접 그린다. 필요하면 SA에서 참고 그림만 고른다.

## 4. 개념·퀴즈 메모
- 개념: 끓는점·녹는점(=어는점)은 물질의 특성이다 / 물질의 양에 관계없이 일정하다(양이 많으면 도달 시간만 길어짐) / 상태가 변하는 동안 온도가 일정하다 / 그래프로 물질을 구별할 수 있다
- 교과서·지도서에 없는 내용(예: 압력과 끓는점이 범위 밖이면)은 S0 대조에서 뺀다.
- 퀴즈 4~5문항, 그래프 해석 문항 포함. 보기 형식은 design.md 5장 규칙.

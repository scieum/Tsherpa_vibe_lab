## 3-1. 모바일·태블릿 대응 (S3 구현 규칙)

템플릿이 이미 처리하는 것: 768px 미만이거나 터치 기기면 제어 패널이 ⋮ 메뉴/하단으로 감, 가로 모드 레이아웃(`orientation: landscape`). 그 위에 이 단원이 지킬 것:

| 화면 | 캔버스 배치 |
|---|---|
| PC·태블릿 가로 (≥ 1024px) | 장면(위, 넓게) + 아래에 피라미드 \| 그래프 나란히 |
| 태블릿 세로 (768~1023px) | 장면 위, 피라미드·그래프 아래 나란히 (글자 크기 ↓) |
| 휴대폰 세로 (375·412px) | 장면 → 피라미드 → 그래프 **세로로 쌓음**. 그래프는 높이 줄이고 범례를 아래로 |
| 휴대폰 가로 (844×390) | 장면 \| 피라미드 좌우 2칸, 그래프는 탭(장면/그래프)으로 전환 |

- **배경 자르기**: 캔버스 비율이 바뀌면 배경은 `cover` 방식으로 꽉 채우고 **아래(땅) 기준 정렬** → 세로 화면에서는 하늘·양옆 나무가 잘리고 땅은 남음.
- **생물 크기**: 캔버스 높이에 비례 (풀 < 임팔라 < 들개 순서 유지). 최소 크기를 둬서 폰에서도 들개 무늬가 보이게.
- **생물 개수**: 화면 넓이에 따라 아이콘 1개가 나타내는 개체수를 바꿈 (PC 최대 약 40개, 폰 최대 약 15개). 실제 숫자는 피라미드·그래프 라벨에 따로 표시 → 작은 화면에서도 겹침 최소화.
- **선명도**: `devicePixelRatio`만큼 캔버스 해상도를 올리고 `imageSmoothingEnabled = false` → 레티나 폰·태블릿에서도 도트가 흐려지지 않음.
- **터치**: 교란 버튼 6개는 최소 44×44px, 패널 안 2열×3행 격자. 캔버스 위 드래그 조작은 없음 → `drag`·`zoom` 기능 삭제 후보.
- **창 크기 변경·회전**: `resize` 때 레이아웃만 다시 계산하고 시뮬레이션 상태는 유지.
- **확인**: V 단계에서 1440×900, 2560×1200, 전체화면, 375×667, 412×915(+⋮), 844×390(touch) 캡처. 태블릿 세로 **768×1024**를 시나리오에 추가.

- 복원 한계 시나리오: 화면 문구는 "먹이 관계만으로는 회복되지 않음 / 회복에 매우 긴 시간". "영원히 회복 불가"로 쓰지 않는다. 사라진 영양단계를 다시 들여오면(고롱고사처럼) 회복된다 (교과서 83·85쪽, 지도서 p.281)

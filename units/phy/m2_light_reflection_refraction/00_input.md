## 1. 단원
- 단원명: 빛의 반사와 굴절
- 학년: 중2
- 영역: phy
- 영어 폴더명: m2_light_reflection_refraction

## 2. 성취기준
- [9과10-01] 빛의 반사와 굴절의 원리를 이해하고, 물체를 보는 과정을 빛의 경로를 이용하여 표현할 수 있다.
- 성취기준 해설: 실험을 통해 빛의 반사, 굴절의 특징을 확인하고, 굴절 법칙은 정량적으로 다루지 않는다.
- 출처: 2022 개정 교육과정 과학과 중학교 '(10) 빛과 파동' (나무위키 2차 자료, 공식 원문 대조는 G4에서)

## 3. 조작 변수
- 빛의 성질: 반사 / 굴절 (선택)
- 상단 물질: 공기 / 물 / 유리 (선택)
- 하단 물질: 공기 / 물 / 유리 (선택)
- 입사각: 0 ~ 85°, 1° 단위, 처음 45°
- 표시 요소(켜고 끄기): 법선, 각도기, 각도, 경계선, 일부 반사 — 굴절률(n 값) 표시는 넣지 않는다

## 4. 개념·퀴즈 메모
- 개념: 반사 법칙(입사각 = 반사각, 법선 기준), 굴절 현상(정성: 다른 물질로 들어갈 때 꺾임, 어느 쪽으로 더 꺾이는지), 물체를 보는 과정(빛의 경로)
- 굴절 법칙 수식(스넬 법칙)과 굴절률 수치는 개념·퀴즈에 쓰지 않는다. 시뮬레이션 내부 계산에만 쓴다.
- 퀴즈 3문항 이상

## 1. 단원
- 단원명: 산화·환원 반응 (Ⅰ-2 산화·환원 반응의 규칙성 / 생활 주변의 산화·환원 반응)
- 학년: 고1 (통합과학2, 신영준)
- 영역: integrated_science
- 영어 폴더명: h1_redox

## 2. 성취기준
- [10통과2-01-03] 자연과 인류의 역사에 큰 변화를 가져온 광합성, 화석 연료 사용, 철의 제련 등에서 공통점을 찾아 산화와 환원을 이해하고, 생활 주변의 다양한 변화를 산화와 환원의 특징과 규칙성으로 분석할 수 있다.
- 출처: 통합과학2 지도서 (S0에서 쪽 번호 확인), 교과서 38~47쪽

## 3. 조작 변수
- 모드 3개 (한 페이지)
  1. **산소의 이동**
     - 산화 구리(II) + 숯가루 가열: 검은색 → 붉은색 구리, 발생한 이산화 탄소로 석회수가 뿌옇게 흐려짐 (교과서 탐구 「산화 구리(II)를 숯가루와 함께 가열할 때의 변화 관찰하기」)
     - 산화 구리(II) + 수소 가열 (CuO + H₂ → Cu + H₂O): 교과서 p.65 (아래 R 대조 결정 참고)
     - 용광로 철의 제련: Fe₂O₃ + CO → Fe + CO₂ (교과서 생활 주변 반응)
     - 조작: 반응 고르기, 가열 시작/정지, 입자 모형에서 산소 원자가 옮겨 가는 애니메이션, 산화(산소 얻음)/환원(산소 잃음) 표시
  2. **전자의 이동**
     - 질산 은 수용액 + 구리줄: 은이 석출되고 용액이 푸른색으로 변함 (교과서 탐구)
     - 마그네슘 연소: Mg → Mg²⁺, O → O²⁻ (교과서)
     - 조작: 반응 고르기, 시간 진행, 전자 이동 애니메이션, 산화(전자 잃음)/환원(전자 얻음) 표시
     - 황산 구리 수용액 + 아연 (지도서 p.114), 금속 모양 고르기 (아래 R 대조 결정 참고)
  3. **생활 속 산화·환원**: 광합성, 세포호흡, 메테인 연소, 철이 녹스는 반응, 철의 제련 카드. 학생이 산화되는 물질과 환원되는 물질을 골라 판정 받기

### R 대조 결정 (2026-11-12, 위 내용보다 우선)
- 산화 구리(II) + 수소: '심화' 표시 없이 넣는다. 출처는 교과서 p.65 개념 적용하기 1 (나)와 p.163 해설, 지도서 p.111. 실험 장치(유리관 속 산화 구리 가열 + 수소 흘림 → 붉은 구리·물방울)는 코드로 그리고 입자 모형도 함께 보여 준다. 고등 화학 교과서 출처는 필요 없다 (사용자: 시중 문제집에 흔한 반응)
- 황산 구리 수용액 + 아연(Zn + Cu²⁺ → Zn²⁺ + Cu): 전자의 이동 모드의 세 번째 반응으로 넣는다. 출처는 지도서 p.114 단원 평가 03~04. 아연 표면에 붉은 구리가 붙고 푸른 용액이 옅어지는 모습을 보여 준다
- 금속 모양 고르기(직선·하트·나선): 넣는다. 그 모양을 따라 은이나 구리가 석출된다. 근거는 교과서 p.42 "원하는 모양으로 만들어"
- 산화수: 넣지 않는다 (지도서 p.15·p.84·p.90 "산화수는 다루지 않는다")
- 표현: "산화와 환원은 항상 동시에 일어난다" (지도서 p.84·p.86·p.88, 교과서 p.41·p.43)
- 광합성·세포호흡 반응식은 교과서 p.44 식을 쓴다 (지도서 식과 다름). 지도서 p.89 "산소는 전자를 잃어 환원된다"는 오류이므로 옮기지 않는다
- 생활 속 카드 판정은 반응식 완성이 아니라 산화·환원되는 물질 고르기로 한다 (지도서 p.83)
- 오개념 반영: 반응식에 산소가 있어도 모두 산화·환원 반응은 아니다 (p.85), 광합성에서 물의 산화는 산소 이동이 아니라 다른 관점이다 (p.91)

### 사용자 수정 (2026-11-12, 위 내용보다 우선)
- 생활 속 산화·환원 모드: 카드 고르기·판정 방식을 없애고, 다른 모드처럼 **시뮬레이션**으로 바꾼다. 반응은 3가지
  1. 광합성·세포호흡 (한 세트, 교과서 p.44): 광합성(CO₂ 환원, H₂O 산화)과 세포호흡(포도당 산화, O₂ 환원)이 서로 반대 방향으로 이어지는 순환
  2. 메테인 연소 (교과서 p.45): CH₄ 산화, O₂ 환원
  3. 철이 녹스는 반응 (교과서 p.42): 철 산화, 산소 환원
  - 철의 제련은 산소의 이동 모드에 이미 있으므로 이 모드에서 뺀다
- 전자의 이동: 질산 은 + 구리, 황산 구리(II) + 아연은 페트리 접시가 아니라 **비커**(옆에서 본 모습)로 그린다. 금속 모양(직선·하트·나선)은 비커 속에 매단 금속으로 보여 준다
- 전자 모형: 구리(아연) 원자 1개만 산화되지 않고, 시간이 지나면서 **여러 원자가 차례로** 전자를 잃고 이온이 되어 용액으로 나가게 한다 (석출되는 은·구리 원자도 그만큼 늘어남, 개수 비 Cu 1 : Ag 2, Zn 1 : Cu 1)
- 입자 모형의 결정·분자 구분 (사용자 지적, 2026-11-12): 이온 결합 물질(산화 구리(II), 산화 철(III), 산화 마그네슘)과 금속(Cu, Fe, Ag, Zn, Mg)은 **입자가 빽빽하게 쌓인 결정 조각**으로 그리고, 분자 하나로 묶어 그리지 않는다 (교과서 p.41 그림 Ⅰ-12). 분자 물질(CO, CO₂, H₂, H₂O, O₂, CH₄, 포도당)만 낱개 분자로 그린다. 탄소(숯가루)는 교과서처럼 낱개 원자로 그린다. 산소의 이동은 결정 표면의 O가 떨어져 나와 C·CO·H₂ 쪽으로 붙는 모습으로 보여 준다
- 삽화 (GQ 2회 실패 → 사용자 승인, 2026-11-12): 정적 기구 6장은 Higgsfield 이미지(`contents/*.webp`, 출처는 01_spec.json `media`). 가루 색 변화·불꽃·기포·석회수 흐림·녹·석출·입자·라벨은 코드로 이미지 위에 그린다. 이어서 사용자 요청으로 비커·용광로·마그네슘(집게·램프)도 이미지 3장 추가, 모든 장면의 정적 기구는 이미지

- 사용자 수정 2 (2026-11-12): 생활 속 반응을 광합성 / 세포호흡 / 메테인의 연소 / 철이 녹스는 반응 4개로 나눈다 (광합성·세포호흡 세트 해제). 산소의 이동: 석회수가 뿌옇게 흐려지는 모습을 분명히, O 원자는 각자 동시에 이동, 분자는 가로로, 산화·환원 꼬리표는 같은 높이. 철의 제련: CO·CO₂를 세로로 쌓지 않는다
- 사용자 요청 (2026-11-17): 산소의 이동에 ④ 마그네슘 + 이산화 탄소(드라이아이스) 반응 추가 — 2Mg + CO₂ → 2MgO + C, 결과 흰색 가루(MgO) + 검은색 가루(C) (지도서 p.120 논술형 02)
